## 🚀 시뮬레이터 주요 핵심 기능 (Ver 4.2)

1. **5채널 일체형 서라운드 뷰 룸미러 (CMS & DSM 통합)**
   - **CH-1**: 상단 내장 렌즈 연동 운전자 안면/동공 DSM 카메라 (실시간 웹캠 영상 연동)
   - **CH-2 / CH-3**: 좌/우측 사각지대 디지털 사이드미러 (BSD 사각지대 차량 접근 시 시각·청각 경고)
   - **CH-4**: 전방 ADAS 카메라 (선행차 감속 연동, 3차선/갓길 차선 인식)
   - **CH-5**: 후방 지능형 카메라 (우리 차 감속/정차 시 직후방 차량 안전거리 8.5m 감속 정차 연동)

2. **운전자 생체감시 동공 개도율 3단계 정밀 판정**
   - **양안 개방 (95%)**: 정상 주행 유지 (초록색 OSD)
   - **단안 윙크/감김 (45%)**: 주의 경고 (주황색 바운딩 박스)
   - **양안 완전 감김 (0%)**: 10초 카운트다운 ➔ 부드러운 코사인 S-커브 회피 기동 (우측 9.2° 조향 ➔ 카운터 스티어 ➔ 갓길 0.0° 안착)

3. **실시간 심전도(ECG) 펄스 파형 & 3자 e-Call 패킷**
   - 우측 상단 실시간 P-Q-R-S-T 심전도 파형 모니터링 (심박수 연동)
   - 비상 정차 즉시 119 소방청, 운송회사 관제실, 보호자(`010-5121-1353`) 3자 동시 e-Call 구난 가동

4. **10대 인터랙티브 컨트롤 독 (마우스 클릭 & 키보드 단축키 지원)**
   - `[SPACE]`: 운전자 기절 / 비상 정차
   - `[A]`: 급발진 150kgf 물리 제동
   - `[F]`: 침수 도어유리 자동 파쇄 (300N 텅스텐 펀치)
   - `[B]`: EV 배터리팩 STF 쉴드 하부 충돌 방호
   - `[L]`: 좌측 본선 회피 추월
   - `[TAB]`: 전체화면 토글
   - `[T]`: 실전 발표 5분 타이머 (녹색 ➔ 황색 ➔ 적색)
   - `[S]`: 음향 즉각 음소거(MUTE) 토글
   - `[R]`: 시스템 전체 초기화 (리셋)
   - `[Q]`: 시뮬레이터 종료

## 💻 빠른 설치 및 실행 방법 (Windows)

### 방법 1. 원클릭 실행 (가장 추천)
바탕화면 또는 저장소 폴더에서 **`세이프티온_디지털룸미러_실행.bat`** 파일을 더블클릭합니다.

### 방법 2. 파이썬 직접 실행
```bash
# 1. 저장소 복제 (Clone)
git clone https://github.com/turtle-scanner/SafetyOn-Digital-Mirror.git
cd SafetyOn-Digital-Mirror

# 2. 필수 라이브러리 설치
pip install -r requirements.txt

# 3. 시뮬레이터 실행
python safetyon_cms_dsm.py
```
